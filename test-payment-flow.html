🧪 Тест API Платежів NextStep

Цей файл дозволяє протестувати всі API endpoint'и для роботи з платежами та курсами.

1️⃣ Ініціалізація платежу

POST https://nextsteap.api-dev.bmax-edu.website/api/payments/course/{courseId}

2️⃣ Перевірка статусу платежу

GET https://nextsteap.api-dev.bmax-edu.website/api/payments/{paymentId}/status

3️⃣ Успішна оплата

GET https://nextsteap.api-dev.bmax-edu.website/api/payments/course/{courseId}/success

4️⃣ Невдалий платіж

GET https://nextsteap.api-dev.bmax-edu.website/api/payments/{paymentId}/failed

5️⃣ Перевірка доступу до курсу

GET https://nextsteap.api-dev.bmax-edu.website/api/enrollments/course/{courseId}

6️⃣ Всі куплені курси

GET https://nextsteap.api-dev.bmax-edu.website/api/enrollments

7️⃣ Доступ до безкоштовного курсу

GET https://nextsteap.api-dev.bmax-edu.website/api/enrollments/free/{courseId}

8️⃣ Адмін - Всі платежі

GET https://nextsteap.api-dev.bmax-edu.website/api/payments

9️⃣ Адмін - Підтвердження платежу

POST https://nextsteap.api-dev.bmax-edu.website/api/payments/{paymentId}/confirm
