# Виправлення проблем з уроками

## Опис проблем та їх вирішення

### 1. Проблема з лекціями - можна додати лише контент АБО файл

**Проблема**: При створенні лекції можна було додати лише текстовий контент АБО файл, але не обидва одночасно.

**Вирішення**: 
- Додано нову вкладку "Текст + Файл" для типу "mixed"
- Оновлено логіку створення та редагування лекцій
- Тепер можна комбінувати текстовий контент з файлом

### 2. Помилка при створенні тестів з зовнішнім посиланням

**Проблема**: Неправильне поле `source_type` - використовувалося `url` замість `external`.

**Вирішення**:
- Змінено `source_type` з `url` на `external` для зовнішніх посилань
- Оновлено всі компоненти (AddLesson, LessonEdit, LessonView)
- Виправлено валідацію та відображення

### 3. Помилки при створенні додаткових матеріалів

**Проблема**: Неправильна обробка файлів для додаткових матеріалів.

**Вирішення**:
- Виправлено логіку передачі файлів в API
- Завжди використовується поле `material_file` для файлів
- Оновлено розмір файлів до 100MB відповідно до документації
- Додано правильну валідацію для обов'язкових полів

### 4. Проблеми при редагуванні уроку

**Проблема**: При редагуванні не змінювалися контент та матеріали уроків.

**Вирішення**:
- Виправлено логіку оновлення в API
- Додано підтримку mixed типу для лекцій при редагуванні
- Оновлено автоматичне визначення активної вкладки на основі існуючого контенту

### 5. Проблеми з прикріпленням файлів при редагуванні

**Проблема**: При редагуванні матеріалів змінювався лише тип, а файл не прикріплявся.

**Вирішення**:
- Виправлено логіку передачі файлів при оновленні
- Спрощено обробку файлів в API
- Додано правильну валідацію файлів

## Оновлення API

### Endpoints
- `GET /lessons/manage/module/{moduleId}` - отримання уроків модуля
- `GET /lessons/manage/{lessonId}` - отримання уроку за ID
- `POST /lessons/manage` - створення уроку
- `POST /lessons/manage/{lessonId}` - оновлення уроку
- `DELETE /lessons/manage/{lessonId}` - видалення уроку
- `PUT /lessons/manage/{lessonId}/position` - зміна позиції уроку
- `POST /lessons/manage/positions` - масова зміна позицій

### Типи контенту лекцій
- `text` - тільки текстовий контент
- `file` - тільки файл
- `mixed` - текст + файл

### Типи джерел тестів
- `external` - зовнішнє посилання (Google Forms)
- `internal` - внутрішній тест

### Типи додаткових матеріалів
- `text` - текстовий контент
- `url` - URL посилання
- `file` - звичайний файл
- `video` - відео файл
- `image` - зображення

## Обмеження файлів
- Максимальний розмір: 100MB
- Дозволені типи: всі типи файлів
- Шлях збереження:
  - Лекції: `storage/app/public/lessons/lectures/`
  - Матеріали: `storage/app/public/lessons/materials/`

## Компоненти, що були оновлені

1. **AddLesson.vue** - створення уроків
2. **LessonEdit.vue** - редагування уроків
3. **LessonView.vue** - перегляд уроків
4. **api.js** - API методи для роботи з уроками

## Тестування

Для тестування виправлень:

1. Створіть нову лекцію з типом "mixed" (текст + файл)
2. Створіть тест з зовнішнім посиланням (Google Forms)
3. Створіть додатковий матеріал з файлом
4. Відредагуйте існуючі уроки
5. Перевірте, чи правильно відображаються всі типи контенту

## Важливі зауваження

- Всі файли тепер мають ліміт 100MB
- Для лекцій можна комбінувати текст і файл
- Тести з зовнішніми посиланнями використовують `source_type: 'external'`
- Додаткові матеріали завжди використовують поле `material_file` для файлів
