## Структура Фінансового модуля

```
Фінансовий модуль
├── Управління платежами (активна вкладка)
│   ├── Фільтри (статус, дати, пошук)
│   ├── Статистика (загальна, очікуючі, завершені, дохід)
│   ├── Список платежів з пагінацією
│   └── Модальні вікна (деталі, підтвердження/відхилення)
├── Фінансова аналітика (заглушка)
└── Звіти (заглушка)
```

## API функції

Фінансовий модуль використовує ті самі API функції, що й раніше:
- `getAdminPayments()` - отримання списку платежів
- `confirmPayment()` - підтвердження платежу
- `rejectPayment()` - відхилення платежу
- `getPaymentDetails()` - деталі платежу
- `getPaymentStatistics()` - статистика платежів

## Переваги нової структури

1. **Краща організація**: Всі фінансові функції в одному місці
2. **Масштабованість**: Легко додавати нові фінансові функції
3. **Зручність**: Система вкладок для навігації між функціями
4. **Консистентність**: Єдиний інтерфейс для всіх фінансових операцій
